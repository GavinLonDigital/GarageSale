# Generate GarageSale Redesign Ideas

I am experimenting with different visual designs for an existing e-commerce
web application called GarageSale.

The application is already built and functional. Project-level engineering
instructions and a dedicated `live-visual-redesign` skill already define the
technical constraints for implementing these transformations.

Your job is therefore ONLY to help me create creative art-direction prompts
for visual redesign experiments.

Generate 10 dramatically different visual directions for GarageSale.

Explore genuinely different design languages rather than minor variations of
the same modern e-commerce aesthetic. Consider directions inspired by
editorial design, historical design movements, architecture, print,
fashion, luxury, technology, industrial design, popular culture, or other
interesting visual influences.

For each idea provide:

1. A short descriptive name.
2. A concise prompt that I can give directly to Codex.

Keep each Codex prompt short — approximately 50–100 words.

Each prompt should:

- Begin with: "Use the `live-visual-redesign` skill."
- Describe the overall creative direction and desired visual character.
- Give enough art direction to inspire a coherent transformation.
- Encourage the model to exercise its own design judgement and creativity.
- Aim for a substantial, immediately noticeable transformation.

Do NOT include implementation instructions about CSS, Razor, Blazor,
Hot Reload, Docker, Git, routes, data bindings, business logic, event
handlers, authentication, responsive implementation, or preserving
functionality.

Those engineering constraints are already defined elsewhere.

Do NOT prescribe individual CSS properties, exact pixel measurements,
specific component changes, or step-by-step implementation instructions.

Treat each prompt as an art director giving a talented designer a creative
brief, rather than a developer specifying how the design must be implemented.

Make the 10 directions visually diverse enough that applying them to the
same GarageSale application would produce clearly different results.
